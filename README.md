# 📦 Уцененные товары — складской сервис

Веб-сервис для публикации уцененных товаров с админ-панелью, корзиной, фотогалереей, бэкапом и статистикой. Готов к развёртыванию в **Timeweb Cloud** через Dockerfile (App Platform).

## ✨ Возможности

### Для покупателей
- 🏷️ Карточки товаров (фото, номер, цена, неисправность, дата)
- 🖼️ Подробная карточка с галереей и **зум-просмотром** (колесо мыши, кнопки, pinch-zoom на телефоне)
- 🛒 Корзина (хранится в браузере)
- 🔍 Поиск, фильтры по категории/статусу/акциям
- 💰 Сортировка по цене (↑↓), по дате
- 📋 Кнопка **«Как заказать?»** с анимированной подсветкой
- 📞 Копирование номера и быстрый переход в мессенджер
- 🌙 Светлая и **тёмная темы**
- 📱 Полная адаптация под телефон и ПК

### Для администратора
- 🔐 Вход по паролю (по умолчанию `010203`, меняется в настройках)
- ➕ Добавление, редактирование, удаление товаров
- 📁 Управление категориями (создание, переименование, удаление)
- 📷 Загрузка до **5 фото** на товар с автооптимизацией
- ⭐ Установка **главного фото**, удаление любого фото
- 🎨 **Выделение карточек** 5 цветами с произвольным текстом-плашкой (СУПЕР ВЫГОДНО, НИЗКАЯ ЦЕНА и т.п.)
- 📌 **Закрепление карточек** над остальными
- 🚦 Статусы товаров (в наличии / бронь / продано)
- 📐 Поля веса и габаритов (Д×Ш×В)
- ☑️ **Массовое выделение** карточек и удаление пачкой
- 📊 Статистика: посетители, товары, по категориям, по статусам, график 7 дней
- 💾 **Бэкап одной кнопкой**: ZIP с CSV-таблицей, фото по папкам и копией БД
- ⚙️ Полные настройки магазина (название, телефон, мессенджер, текст инструкции, пароль)
- 👀 Счётчик посетителей (уникальные за день, увеличивается раз в день на сессию)

## 🚀 Развёртывание в Timeweb Cloud (App Platform / Dockerfile)

1. **Распакуйте архив** и загрузите содержимое в свой Git-репозиторий (GitHub/GitLab/Bitbucket).
2. В **Timeweb Cloud** → **Apps** → **Создать приложение** → **Из Dockerfile** → подключите репозиторий.
3. **Порт**: укажите `8000` (Timeweb автоматически проксирует его на 80/443).
4. **Volume для данных** (важно, чтобы данные не терялись при пересборке):
   - `/app/data` — база SQLite
   - `/app/static/uploads` — фотографии товаров
5. **Переменные окружения** (необязательно):
   - `ADMIN_PASSWORD` — стартовый пароль (по умолчанию `010203`). Лучше задать здесь и потом менять через настройки.
   - `SECRET_KEY` — длинная случайная строка (для подписи сессий). Если не задать — сгенерируется при старте, но при рестарте сессии слетят.
6. Запустите сборку. После запуска приложение будет доступно по выданному адресу.

### Локальный запуск (для теста)

```bash
docker build -t uvenka .
docker run -p 8000:8000 -v $(pwd)/data:/app/data -v $(pwd)/static/uploads:/app/static/uploads uvenka
# открыть http://localhost:8000
```

Или без Docker:
```bash
pip install -r requirements.txt
python app.py
```

## 🔑 Первый вход

- Откройте сайт → нажмите 🔑 в правом верхнем углу.
- Введите пароль: **`010203`**.
- Сначала зайдите в **⚙️ Настройки** и:
  - Смените пароль на свой;
  - Укажите ваш номер телефона;
  - Вставьте ссылку на ваш мессенджер (Telegram/Max/WhatsApp/…);
  - Подправьте название магазина и текст «Как заказать?».
- Затем создайте категории (📁) и добавляйте товары (➕ Новый товар).

## 💾 Бэкап и восстановление

- Кнопка **💾 Бэкап** в админ-панели скачивает ZIP-архив:
  - `products.csv` — таблица всех товаров (UTF-8, разделитель `;`, открывается в Excel/Google Sheets)
  - `categories.csv` — таблица категорий
  - `settings.json` — все настройки (кроме пароля)
  - `photos/<id>_<номер>_<название>/` — папки с фото каждого товара (главное помечено `main_`)
  - `store.db` — полная копия БД (SQLite)
- **Восстановление**: положите `store.db` в `/app/data/`, а содержимое `photos/` распакуйте обратно в `/app/static/uploads/` (как плоский список файлов).

## 🛠️ Технологии

- **Backend**: Flask 3 + SQLite + Pillow (для оптимизации фото)
- **Frontend**: чистый JS + CSS (никаких сборщиков и npm — всё работает «из коробки»)
- **Сервер**: Gunicorn (2 воркера, 4 потока)

## 🔐 Безопасность

- Пароль администратора хранится в БД (можно сменить через настройки).
- Cookie-сессии подписываются `SECRET_KEY`. **На продакшне обязательно задайте свой `SECRET_KEY`** через переменные окружения Timeweb.
- Все API-эндпоинты модификации требуют админ-сессии.
- Фотографии при загрузке прогоняются через Pillow (защита от подозрительных файлов).

## ❓ Частые вопросы

**Где взять ссылку на Max/Telegram?**
- Telegram: `https://t.me/+79996164994` или `https://t.me/username`
- Max: укажите ссылку в формате, который вам выдаёт Max.

**Можно ли использовать с PostgreSQL?**
- В текущей реализации — SQLite (проще для одного сервера). При желании можно мигрировать на PG (заменить `sqlite3` на `psycopg`).

**Фото большие — будет тормозить?**
- Каждое фото при загрузке автоматически сжимается до 1800 px по длинной стороне и переводится в оптимизированный JPEG/WebP. На карточках используется `loading="lazy"`.
